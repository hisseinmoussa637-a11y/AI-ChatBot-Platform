# AI ChatBot Platform

## Overview
A modern AI chat application built with React and Node.js.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- AI: OpenAI API
- Auth: JWT

## Getting started

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Environment
Set the values in `backend/.env` and `frontend/.env`.

## Deployment
This app is ready to deploy on Vercel + Render + MongoDB Atlas.
